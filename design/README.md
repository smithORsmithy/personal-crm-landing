# Handoff: лендинг «Личная CRM»

## Обзор
Одностраничный статичный лендинг личной CRM для людей с большим количеством знакомств. **Одно целевое действие** — перейти в приложение по кнопке «Открыть мою CRM». Других ссылок, форм и навигации нет.

**Стек:** Astro + Tailwind CSS v4, статическая сборка (`output: 'static'`), без клиентского JS.

## О дизайн-файлах
Файлы в `design/` — **дизайн-референсы в HTML**, а не продакшн-код. Задача — воссоздать их в Astro + Tailwind 4 чистой семантической вёрсткой. Открыть референс: `design/Landing.dc.html` в браузере (рядом должен лежать `support.js`). Файл — холст с несколькими раундами вариантов; **реализуем только два**:
- **2a** — мобильная версия (390px), секция `#t2`
- **3a** — десктопная версия (1440px), секция `#t3`

Раунд `#t1` (1a–1d) — отброшенные ранние варианты, игнорировать.

## Fidelity
**High-fidelity.** Цвета, шрифты, размеры, отступы финальные. Воспроизводить точно. Тексты в макете — финальные (отличаются от `copy.md` правками заказчика; источник истины — макет и этот README).

## Адаптив
Mobile-first. Мобильная раскладка (2a) до `lg` (1024px), десктопная (3a) от `lg`. Десктоп-контейнер: `max-width: 1440px; margin: 0 auto`, горизонтальные поля 120px (на 1024–1280 можно уменьшить до 64px). Между 390 и 1024 мобильная раскладка тянется по ширине (колонка контента можно ограничить `max-width: 560px` по центру).

### 2. Проблема
Верхний разделитель: `border-top: 1px dashed divider`.
**Мобайл:** padding 56px 24px 48px, колонка gap 26px: кикер «знакомо?» → H2 (margin-top −14px) → список → листок.
**Десктоп:** padding 104px 120px, grid `1fr 1.2fr`, gap 80px. Слева: кикер, H2, листок (margin-top 36px, max-width 440px). Справа: список сеткой 2×2 (gap 40px 44px), padding-top 56px.

- H2: «Знакомств всё больше — а **людей** запоминаешь реже» — «людей» скриптом
- Пункты списка (маркер «•» 800 20px в колонке 22px, gap 10px; между пунктами 18px):
  1. После форума в телефоне двадцать новых номеров, а через неделю уже не вспомнить, кто есть кто.
  2. Человек радостно здоровается, а ты лихорадочно вспоминаешь, где вы виделись.
  3. «Давай созвонимся после праздников» — и оба забыли.
  4. Тебе рассказали о новой работе или переезде, а при следующей встрече ты не можешь об этом спросить — просто не помнишь.
- Листок со скотчем (padding 22px 20px 20px; десктоп 30px 28px 26px):
  - строка 1 (Manrope 16/18px, ink-2): «Дело не в том, что люди тебе безразличны.»
  - строка 2 (Marck Script 25/30px, accent, mt 6/8px): «Просто память не рассчитана на сотни знакомств.»

### 3. Решение
Разделитель сверху как выше.
**Мобайл:** padding 48px 0, колонка gap 24px. Текстовый блок (padding 0 24px, gap 14px): кикер «решение», H2 (mt −6px), абзац. Фото 240px, отступы 0 14px. Шаги (padding 0 24px, gap 22px): каждый — grid `44px 1fr`, gap 12px. Плашка в пунктирной рамке (padding 14px 16px, 15px/1.5).
**Десктоп:** padding 104px 120px, колонка gap 64px. Ряд 1: grid `1fr 1.2fr`, gap 80px — текст слева, фото 380px справа. Ряд 2: шаги в 3 колонки, gap 48px, внутри каждой колонкой (цифра → заголовок → описание, gap 10px). Ряд 3: пунктирная плашка `align-self:flex-start`, padding 16px 22px, 17px.

- H2: «Одно место для всех, кого ты знаешь **лично**» — «лично» скриптом
- Абзац: «Записная книжка о людях, которые тебе дороги. Три простых шага:»
- Шаги:
  1. **Познакомились — добавь человека** — Имя, откуда вы знакомы, телефон и почта.
  2. **Поговорили — допиши заметку** — О чём говорили и о чём договорились. У каждой заметки есть дата, свежие — сверху.
  3. **Скоро встреча — найди и вспомни** — Достаточно ввести часть имени, и перед тобой вся история общения.
- Плашка: «Открывается в браузере на компьютере и на телефоне — контакты везде одни и те же.»

### 4. Выгоды (тёмный блок)
bg ink, текст paper.
**Мобайл:** padding 48px 24px 52px, колонка gap 22px; пункты gap 22px.
**Десктоп:** padding 104px 120px, grid `1fr 2fr`, gap 80px — H2 слева, справа пункты сеткой 2×2 (gap 48px 56px).

- H2: «Что **изменится**» — «изменится» скриптом, цвет accent-light
- Пункт: grid `24px 1fr` (десктоп 28px), gap 14px (16px). Чекбокс: 18×18 (20×20), `border:1.5px solid accent-light`, внутри «×» Marck Script 20px (22px) accent-light, margin-top 3px (4px). Заголовок → описание (margin-top 5px / 8px).
  1. **Знакомься смело** — Расширяй круг сколько хочешь: каждый новый человек останется с тобой, а не потеряется среди сотен номеров.
  2. **Люди чувствуют, что о них помнят** — Ты спрашиваешь, как прошёл переезд, и возвращаешься к тому, о чём договорились. Из таких мелочей и растёт доверие.
  3. **Каждый разговор продолжает прошлый** — Не нужно начинать с «напомни, где мы виделись» — сразу спрашиваешь: «Как твоя последняя поездка?»
  4. **Помни о главном** — Имена и договорённости записаны, а внимание остаётся на собеседнике.

### 5. Призыв к действию

**Десктоп:** padding 104px 120px 72px, grid `1.05fr 1fr`, gap 80px, align center. Слева фото 480px, справа колонка gap 22px: H2, абзац (max-width 460px), кнопка (mt 14px). Ниже футер: `border-top:1px dashed divider`, padding 28px 120px 36px, «личная crm» 800 14px muted-2.

- H2: «Каждое знакомство достойно **продолжения**» — «продолжения» скриптом
